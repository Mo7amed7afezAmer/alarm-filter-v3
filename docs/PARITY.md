# Parity checklist — FR-01 … FR-70, NFR-01 … NFR-43

Source of the requirement text: `REQUIREMENTS.md` §3 and §4. Decisions: `docs/DECISIONS.md` (rows cited by their name; e.g. "G-T12 cache bits" = Clarifications row "G-T12 cache bits").
Rule (Clarifications "G-T16 parity rows"): an FR/NFR changed or dropped by a recorded decision is green when its row names the decision and the test of the replacement behaviour.

Notes on running:
- Tests marked `skipIf(!testDatabaseUrl)` need `TEST_DATABASE_URL` → `alarms_test` (apps/web/test/*, packages/db/src/*, apps/worker/src/*.db.test.ts, auth.test authorizeCredentials).
- `tests/ops/compose.test.ts` needs `docker compose` (Caddyfile block runs without it). `tests/ops/stack.test.ts` needs `OPS_BASE_URL` against a running stack; the restore case also needs `OPS_RESTORE=1`.
- `apps/web/e2e/*.spec.ts` run with `pnpm e2e` (`next dev` :3200; timing test on :3201).
- "M-n" refers to the manual checks at the end; they are done by a person before the v1.0.0 tag.
